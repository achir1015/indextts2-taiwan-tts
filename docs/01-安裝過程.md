# 01 安裝過程

這份文件記錄 2026/09/23 在一台 Windows 筆電上，從零開始安裝 IndexTTS2 並架好網頁工具的完整過程，包含途中遇到的每個問題與解法。

> 比喻：安裝就像「開一間錄音室」。
> - **Python 環境**是錄音室的水電
> - **IndexTTS2 程式**是錄音設備
> - **模型檔**是錄音師的「經驗」（約 10 GB）
> - **網頁工具**是櫃台，讓客人（瀏覽器）可以下單

---

## 一、測試機器

| 項目 | 規格 |
|---|---|
| 作業系統 | Windows 11 |
| CPU | 12th Gen Intel Core i5-1240P |
| 顯示卡 | Intel Iris Xe（**沒有 NVIDIA 顯示卡**） |
| 記憶體 | 23.7 GB |
| 已安裝 | Anaconda（`C:\ProgramData\anaconda3`）、git、uv |
| 硬碟空間 | 模型與套件約 15 GB（IndexTTS2 約 10 GB＋台語引擎約 5 GB） |

---
使用 Anaconda Prompt 進行初始化（最推薦）
這是最穩定且不會破壞全域環境變數的方法。

按下鍵盤上的 Windows 鍵，在搜尋列輸入：

Plaintext

Anaconda Prompt
（若安裝的是 Miniconda，請搜尋 Miniconda Prompt）

點擊開啟該終端機。

在終端機內輸入以下指令並按下 Enter：

PowerShell

conda init powershell
驗證方式：終端機應顯示 modified: ...Microsoft.PowerShell_profile.ps1 類似字樣。

完全關閉並重新開啟原本的 PowerShell 視窗，再次輸入 conda --version 驗證是否成功辨識。

方法二：將 Conda 新增至系統環境變數 (Path)
若要在一般 PowerShell 或 CMD 中隨處呼叫 conda，需確保以下三個目錄已加入系統的 Path。

預設安裝路徑通常位於以下位置（請將 achir 換為你的使用者名稱）：

C:\Users\achir\anaconda3

C:\Users\achir\anaconda3\Scripts

C:\Users\achir\anaconda3\Library\bin (若為 Miniconda，通常在 C:\Users\achir\miniconda3)

手動加入步驟：

按下 Win + R，輸入 sysdm.cpl 並按 Enter 開啟「系統內容」。

切換至 進階 頁籤，點擊右下角 環境變數。

在下方「系統變數」或上方「使用者變數」中找到 Path，選取後點擊 編輯。

點擊 新增，依序填入上述三個路徑（請先確認資料夾確實存在）：

C:\Users\achir\anaconda3

C:\Users\achir\anaconda3\Scripts

C:\Users\achir\anaconda3\Library\bin

連續點擊 確定 儲存設定。

重啟 PowerShell，輸入 conda --version 確認輸出版本號。

方法三：確認是否已安裝 Anaconda / Miniconda
若上述路徑皆找不到對應資料夾，代表電腦尚未安裝 Conda：

請至 Anaconda 官網 或 Miniconda 官網 下載 Windows 安裝檔並完成安裝。

安裝完成後，直接開啟 Anaconda Prompt 操作即可。

後續執行原本指令
成功辨識 conda 後，即可接續執行：

PowerShell

conda create -n indextts2 python=3.10 -y
conda activate indextts2
注意： 若在 PowerShell 執行 conda activate 時出現執行原則受限（Script Execution Policy）的錯誤，請以系統管理員身分開啟 PowerShell 並執行：

PowerShell

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
輸入 Y 確認即可


## 二、最終安裝步驟（照做即可）

### 1. 下載程式

```bat
cd %USERPROFILE%
git clone https://github.com/index-tts/index-tts.git
```

再把本 repo 的檔案放到任意資料夾，例如 `E:\Index TTS2\`。

### 2. 雙擊 `install_indextts2.bat`

腳本共 7 步，詳細紀錄寫在 `logs\install_log.txt`：

| 步驟 | 做什麼 | 說明 |
|---|---|---|
| 1 | 偵測顯示卡 | 有 NVIDIA 就裝 CUDA 版 PyTorch，沒有就裝 CPU 版 |
| 2 | 用 Anaconda 建立 Python 3.11 環境 | 位置：`%USERPROFILE%\indextts-py311` |
| 3 | 從官方 `uv.lock` 匯出套件清單 | 版本與官方完全一致 |
| 4 | 安裝 PyTorch 2.8 | CPU 或 CUDA 12.8 |
| 5 | 安裝其他套件 | 另外加裝 imageio-ffmpeg、opencc、soundfile |
| 6 | 下載 IndexTTS-2 模型 | 存到 `%USERPROFILE%\index-tts\checkpoints_2`，約 6 GB |
| 7 | 自我測試 | 產生 `logs\selftest.wav`，看到 `SELFTEST_OK` 就是成功 |

### 3. （選配）雙擊 `install_hokkien.bat`

安裝台語引擎（MERaLiON OmniVoice Hokkien），環境在 `%USERPROFILE%\hokkien-py311`，模型存在 `hf_home\`。成功時會產生 `logs\hokkien_test.wav`。

### 4. 雙擊 `start_server.bat`

- 第一次啟動會自動準備台灣口音的聲音範本（`prepare_voices.py`）
- 有安裝台語引擎的話，會另外開一個最小化視窗執行它
- 瀏覽器會自動打開 <http://127.0.0.1:7861>

## 三、安裝過程遇到的問題與解法

實際安裝時一共踩到 6 個坑，都已經修進腳本裡了。

### 問題 1：壓縮檔版本太舊

- **狀況**：資料夾裡的 `indexTTS2-main.zip` 是 2025/09 的早期版本。它的 `requirements.txt` 需要 `deepspeed`、`WeTextProcessing`（要編譯 pynini），在 Windows 上很難裝起來。
- **解法**：改用官方最新版 `index-tts`（2026/08，支援 Windows、用 `uv.lock` 鎖版本），模型仍用 **IndexTTS-2**。

### 問題 2：「應用程式控制原則已封鎖此檔案」

```
error: Failed to query Python interpreter at `C:\Users\...\.local\bin\python3.11.exe`
  Caused by: 應用程式控制原則已封鎖此檔案。 (os error 4551)
```

- **狀況**：官方建議用 `uv sync`，它會自己下載一份 Python。但那份 Python 沒有數位簽章，被 Windows「智慧型應用程式控制」擋掉了。
- **解法**：改用電腦上已安裝的 **Anaconda** 建立 Python 3.11 環境（有簽章）。uv 只用來「匯出套件清單」和「快速安裝套件」，不讓它自己下載 Python：

```bat
set "UV_PYTHON_DOWNLOADS=never"
conda create -y -p "%USERPROFILE%\indextts-py311" python=3.11
uv export --frozen --no-hashes --extra webui --no-emit-project -o req_full.txt
uv pip install --python "%USERPROFILE%\indextts-py311\python.exe" -r req.txt
```

另外設定 `CONDA_PLUGINS_AUTO_ACCEPT_TOS=yes`，避免新版 conda 卡在服務條款的確認畫面。

### 問題 3：沒有 NVIDIA 顯示卡

- **狀況**：`nvidia-smi` 找不到，只有 Intel Iris Xe 內建顯示卡。
- **解法**：腳本自動改裝 **CPU 版 PyTorch**，下載量從約 2.5 GB 降到約 200 MB。
- **影響**：速度大約是 **每 1 秒語音要算 10~27 秒**（RTF 約 27）。自我測試時，載入模型花 131 秒，4.5 秒的語音花了 124 秒。
  - 網頁會先估計要等多久，並顯示「第幾段 / 共幾段、還要多久」
  - 如果換到有 NVIDIA 顯示卡的電腦，速度可以快 20 倍以上，程式不用改

### 問題 4：繁體字變成「未知字」

```
>> Warning: input text contains 5 unknown tokens (id=2):
   Tokens which can't be encoded:  ['這', '裝', '測', '試', '語']
```

- **狀況**：IndexTTS2 主要用簡體字訓練，有些繁體字它不認得，會直接跳過不唸。
- **解法**：網頁伺服器在送進模型前，先用 OpenCC 把 **繁體轉成簡體**（`engines.py` 的 `prepare_text`）。使用者輸入和畫面顯示仍然是繁體。

### 問題 5：`C:\Users\...\.cache\huggingface` 存取被拒

```
PermissionError: [WinError 5] 存取被拒。: 'C:\\Users\\...\\.cache\\huggingface'
```

- **狀況**：安裝台語引擎時，模型要下載到預設的快取資料夾，但這台電腦的該資料夾權限被鎖住。
- **解法**：在 `install_hokkien.bat` 與 `start_server.bat` 設定 `HF_HOME=%~dp0hf_home`，把快取改放到 E 槽的程式資料夾。

### 問題 6：E 槽不能建立 symlink

```
OSError: [WinError 1314] 用戶端沒有這項特殊權限。
```

- **狀況**：huggingface 下載模型時預設用「捷徑連結（symlink）」，一般權限的 Windows 帳號不能建立。
- **解法**：在 `hokkien_worker.py` 開頭強制改用「複製檔案」：

```python
import huggingface_hub.file_download as _fd
_fd.are_symlinks_supported = lambda *a, **k: False
```

IndexTTS-2 本體則用 `snapshot_download(local_dir=...)` 直接下載成一般檔案，不會遇到這個問題。

### 其他小問題

| 狀況 | 解法 |
|---|---|
| 自動下載聲音範本時，資料集伺服器回傳 HTTP 429（太頻繁） | `prepare_voices.py` 改成遇到 429 等 15、30、45 秒再重試，仍失敗就明確報錯 |
| ffmpeg 同時使用 `silenceremove + areverse + loudnorm` 會卡住 | 樣本整理改成 ffmpeg 只去靜音，音量標準化改用 numpy 處理 |
| 產生長文時看不到進度，以為當掉 | 接上官方的 `gr_progress` 回呼，網頁每 3 秒查詢 `/api/progress` 顯示進度與預估時間 |
| 重新啟動網站會中斷正在產生的語音 | 在說明中提醒；小說劇場另外有「台詞快取」，重做時不會浪費已完成的句子 |

## 四、安裝後的資料夾

```
E:\Index TTS2\
├─ install_indextts2.bat     安裝 IndexTTS2
├─ install_hokkien.bat       安裝台語引擎（選配）
├─ start_server.bat          啟動網站
├─ app\                      網頁工具程式（本 repo）
│  ├─ voices\                8 種聲音樣本（個人資料，不上傳）
│  ├─ outputs\               產生的 MP3（不上傳）
│  ├─ cache\lines\           小說劇場的台詞快取
│  └─ ambience\              使用者上傳的背景音
├─ hf_home\                  台語模型快取
└─ logs\                     安裝與執行紀錄

%USERPROFILE%\index-tts\          IndexTTS 官方程式
%USERPROFILE%\index-tts\checkpoints_2\   IndexTTS-2 模型
%USERPROFILE%\indextts-py311\     IndexTTS2 用的 Python 環境
%USERPROFILE%\hokkien-py311\      台語引擎用的 Python 環境
```
