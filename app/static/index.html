    聲音範本是什麼？

    IndexTTS2 是「聽一段樣本、模仿那個人說話」的模型。就像請一位配音員：樣本是誰、什麼口音、幾歲，產生出來的聲音就像誰。 所以樣本越像「台灣人講話」，成品就越有台灣腔。每種聲音放一段 5~15 秒、清楚、沒有背景音樂的說話錄音即可。
    建議朗讀稿：「今天天氣真好，我們下午去夜市吃蚵仔煎，再買一杯珍珠奶茶。你要不要一起來？記得帶雨傘喔。」

    使用說明

    1. 輸入文字 → 選聲音 → 按「產生 MP3」。第一次產生會比較慢（模型暖身）。
    2. 情緒選「自然」時，語氣會跟著樣本本身；選其他情緒可以調整強度。
    3. 語速是產生後再用 ffmpeg 調整，不會改變音高。
    4. 繁體字會自動轉成簡體再交給模型（發音比較準），不影響你輸入的內容。
    5. 唸錯或唸成大陸讀音的字（例如「垃圾」「星期」），可以改寫成同音字，例如「樂色」。

    關於台語

    IndexTTS2 只會說國語、英語。台語是另外接的實驗性閩南語模型（MERaLiON OmniVoice Hokkien，原本以新加坡福建話為主）， 搭配台灣長輩的聲音樣本使用，腔調接近但不完全等於台灣台語。需要先執行一次 install_hokkien.bat。

    在手機桌面建立捷徑

    • iPhone（Safari）：開啟本網址 → 下方「分享」按鈕 → 「加入主畫面」。
    • Android（Chrome）：開啟本網址 → 右上「⋮」→「加到主畫面」或「安裝應用程式」。
    • 手機要能連到這台電腦：同一個 Wi-Fi 用 http://電腦IP:7861，或用 ngrok 的 https 網址（可安裝成 App）。

    給別人用

    同一個 Wi-Fi 的電腦可以用 http://這台電腦的IP:7861 開啟。要放到網際網路上，建議在 start_server.bat 設定 TTS_PASSWORD 密碼，再用 ngrok 轉出去。 注意：網頁錄音功能只能在 127.0.0.1 或 https 網址下使用。
